Siddhanta's licence allows no derivatives, so its file is the original, unconverted and
unsubset, and it is loaded only when a reader chooses it in settings. The others are WOFF2
conversions of the upstream files (the two Noto variable fonts are fixed at regular weight
and normal width).

The PDFs set Kannada in Nudi. Its files say only "All rights reserved" (Kannada Ganaka
Parishat), so the app uses Noto Sans Kannada instead.
